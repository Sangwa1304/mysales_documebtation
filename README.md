# Documentation MYSALES

Ce dépôt est consacré à la documentation de **MYSALES**, une application de gestion des ventes.

## Objectif

Rassembler les informations nécessaires pour comprendre le projet MYSALES et accompagner son utilisation et son évolution.

## Périmètre documentaire

La documentation peut notamment présenter :
- la finalité et le périmètre fonctionnel de l'application ;
- les processus de gestion des ventes ;
- les fonctionnalités de gestion commerciale ;
- les procédures d'installation et de configuration, lorsqu'elles sont établies ;
- les guides d'utilisation et les notes destinées aux développeurs.

## Projet associé

- Application : [Sangwa1304/mysales](https://github.com/Sangwa1304/mysales)

## Note

Les sections détaillées doivent rester alignées sur les fonctionnalités réellement disponibles dans l'application. Les procédures techniques ne sont pas spécifiées ici tant que la stack et les mécanismes de déploiement ne sont pas confirmés.
